# LLMFarm

Приложение для запуска больших языковых моделей (LLM) прямо на iPhone и iPad, без интернета. Работает на базе [llama.cpp](https://github.com/ggerganov/llama.cpp).

> Это форк. Оригинал: [github.com/guinmoon/LLMFarm](https://github.com/guinmoon/LLMFarm)

## ✨ Возможности

- 🧠 Локальный запуск LLM в формате **GGUF**
- 💬 Чат с историей
- 📚 RAG — поиск по своим документам
- 🎯 Fine-tuning (LoRA)
- 🖼️ Поддержка мультимодальных моделей (LLaVA)
- 🌍 **Русский и английский интерфейс** — перевод с описаниями параметров
- 🔒 Полностью офлайн, без телеметрии

## 🌍 Язык интерфейса

Приложение поддерживает **русский** и **английский** языки. Язык выбирается автоматически по системным настройкам iOS:

- Если язык iPhone — **русский**, интерфейс будет на русском.
- Если любой другой — интерфейс будет на английском (по умолчанию).

Сменить язык можно также отдельно для приложения: **Настройки → LLMFarm → Язык**.

**Что локализовано:**
- Все экраны чата, настроек чата и настроек приложения
- Алерты, кнопки, плейсхолдеры
- Описания параметров в попапах «i» — на русском и английском

## 📱 Требования

- **iOS 16.4+**
- iPhone/iPad с **Apple Silicon** (A14 и новее) для Metal-ускорения
- 4+ ГБ свободной памяти для компактных моделей

## 🚀 Установка

Готовый неподписанный `.ipa` лежит в разделе [Releases](../../releases).

1. Скачай `.ipa` из последнего релиза.
2. Подпиши своим сертификатом через [ESign](https://esign.yyyue.xyz/), AltStore или Sideloadly.
3. Установи на iPhone.

## 🤖 Поддерживаемые модели

Приложение работает с моделями в формате **GGUF**:

| Модель | Размер | Рекомендуемое квантование |
|---|---|---|
| Qwen 2.5 (0.5B–7B) | 0.4–5 ГБ | Q4_K_M |
| Qwenвать 3 (0.6B–8B модели) | 0.5–5 удоб ГБ | Q4_K_M |
| Gemma 2 (2B / 9B) | 1.5–6 ГБ | Q4_K_M |
| Llama 3.2 (1B / 3B) | 0.8–2 ГБ | Q4_K_M |
| Phi-3.5 Mini | 2.4 ГБ | Q4_K_M |
| Mistral 7B | 4.5 ГБ | Q4_K_M |

Скачинее всего с [Hugging Face](https://huggingface.co/models?search=gguf) — ищи по запросу `<название модели> GGUF`.

## 🛠️ Сборка из исходников

Если хочешь собрать сам — есть готовый workflow в GitHub Actions. Просто форкни репозиторий и запусти **Actions → Build iOS App → Run workflow**. Готовый `.ipa` появится в **Releases**.
